# Backup and Recovery

- Automated daily encrypted PostgreSQL backups with at least 30 days retention
- Weekly independent media inventory and object-version verification
- Monthly restore test in an isolated environment
- Pre-deployment database and configuration snapshot
- Quarterly export of redirects, users/roles, content, media metadata, and provider configuration
- Written recovery objectives: database RPO 24 hours or better, RTO 8 hours or better
- Maintain a current emergency contact list and registrar/DNS recovery process
