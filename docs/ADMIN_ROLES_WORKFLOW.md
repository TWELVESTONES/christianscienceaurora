# Admin Roles and Workflow

| Role | Access |
|---|---|
| Administrator | System, users, integrations, security, backups |
| Website Coordinator | Pages, homepage, navigation, campaigns, publishing |
| Events Editor | Events, recurrence, status, calendar feeds |
| Sermon Editor | Sermons, media, transcripts, citations |
| Reading Room Manager | Products, inventory, orders, Reading Room content |
| Sunday School Editor | Activities, stories, family content; cannot bypass review |
| Compliance Reviewer | Rights, permissions, accessibility, youth, publication review |
| Contributor | Draft creation without publishing rights |

Workflow: Draft → Content Review → Rights/Permissions Review → Accessibility Review → SEO Review → Approved → Scheduled/Published → Archived or Re-reviewed.

No single non-administrator role should create, approve, and publish protected or youth content without an independent review step.
