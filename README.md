# ChristianScienceAurora.com

Production-oriented Next.js App Router public website for First Church of Christ, Scientist, Aurora, Colorado.

## Included

- Complete required public information architecture and responsive page templates
- Approved text-only CSA / CHRISTIAN SCIENCE / AURORA wordmark treatment
- Inter Display / Inter CSS typography stack without distributing font files
- Warm white, Aurora teal, periwinkle, restrained Morning Gold design tokens
- Accessible navigation, skip links, visible focus, 17-18px body copy, reduced motion, semantic sections, forms, calendar, media patterns, and print styles
- Production-safe public mode and private church-review mode
- Events month grid, annual list, detail pages, archive behavior, iCal/Google Calendar links, and Event schema
- Sermon library/detail with audio, video, transcript, citation, and rights-review patterns
- Sunday School resource filters, child-friendly pages, youth safeguards, and resource details
- Reading Room, product catalog presentation, and disabled commerce boundaries until approved
- Articles, resources, local branch relationship notice, legal/system pages, sitemap, robots.txt, and llms.txt
- Vendor-neutral adapters for CMS, media, search, payments, email, and analytics
- Local CMS adapter plus Payload-compatible REST adapter
- Contact delivery through console, Resend, or generic webhook providers
- PostgreSQL migration/seed outline, role/workflow documentation, redirect plan, QA matrix, and automated tests
- 46 desktop and 12 mobile public webpage mockups, plus 5 desktop and 5 mobile review-mode detail/transaction templates
- Detailed photography and AI image prompt Word document

## Important

The local seed adapter is for design, content review, and development. Production launch still requires verified church facts, approved photography and permissions, configured CMS/authentication and email providers, legal/privacy review, staging accessibility testing, and final launch-gate approval.
